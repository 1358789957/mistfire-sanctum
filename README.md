# 雾火神殿 Mistfire Sanctum

手机本地就能玩的俯视 3D 领地经营 + 符文战斗。你师从一位魔族学者学会了符文，被王国流放到这座岛：点火、立领地、招麾下、占城寨，择日反攻故土。

四枚符文是四条成长线，等级只涨在自己的路子上，都能一路涨下去：

| 符文 | 打法 | 经验来自 | 技能（解锁等级） |
| --- | --- | --- | --- |
| 力量 | 伤害与速度暴涨，击杀掠夺魔力 | 杀敌 | 裂击1 · 疾驰2 · 掠魔4 · 崩地6 |
| 机械傀儡 | 傀儡代你采集、生产、作战 | 傀儡劳作 | 唤傀1 · 铁令2 · 战傀4 · 集结6 |
| 精密 | 建造打造减耗，布符阵炮台 | 打造与建造 | 测算1 · 速筑2 · 符炮4 · 超载6 |
| 生命 | 造物躯壳死了核心还在，复活保留等级；生命网络越广越难杀 | 治疗与造物 | 唤生1 · 疗愈2 · 网络4 · 群生6 |

## 在手机上玩

### 方法一：电脑开局，手机同 Wi‑Fi 进入（推荐）

在本目录执行：

```bash
python3 -m http.server 8080
```

电脑和手机连同一 Wi‑Fi，手机浏览器打开：

```
http://<电脑局域网IP>:8080
```

Safari / Chrome 都可以。可「添加到主屏幕」，以后离线也能开（需先用 http 访问一次以缓存）。

查 IP 的例子：macOS / Linux 用 `ipconfig getifaddr en0` 或 `hostname -I`。

### 方法二：把文件夹拷进手机

把整个目录拷到手机，用能打开本地网页的 App（如一些文件管理器 + 本地静态服务）指向 `index.html`。

> 直接用 `file://` 打开在部分浏览器会限制音频或存档，优先用本地 http。

## 怎么玩

1. 开局选一枚符文。它决定技能、成长方式，也决定你怎么过夜。
2. 切到 **手斧**，劈到 8 木材，在祭坛点燃流放者的火种。
3. **入夜会有东西来**。按 B 进建造，放一座 **火塔**：塔的光圈内会烧伤来犯者，也替你压住腐化。哨塔会自动放箭，拒马与栅栏拦人。
4. 小地图 **褐色方块** 是其它势力的城寨。清掉驻军，在旗帜处占领，即可招募麾下（6 魂）。占下的地盘会定期上贡，也扩你的麾下上限。
5. 功能建筑各有用处：**工坊** 打造全部配方、**傀儡台** 造傀儡、**复生坛** 用核心复活造物、**粮圃 / 药圃** 定期产出干粮与绷带。
6. 占领两处地盘后，可攻北境 **故土渡口**——反攻之路。北境石环里还有雾狱守卫。
7. 魔力用来放符文技能：击杀、敲晶石都回魔，符文等级越高上限越高。
